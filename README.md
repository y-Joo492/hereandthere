# 여기저기
당신의 여행기록을 남겨보세요.

## 서비스 소개
여행의 순간을 기억하고 간직하세요. 여러분이 남긴 여행 기록과 사진을 통해 소중한 추억을 자주 떠올리고, 그때의 감정과 느낌을 잊지 않도록 도와줄게요. '여기저기'에서 추억을 남겨보세요!

## 주요 기능
-나의 여기저기 모아보기
 국내, 해외 여행기록을 각각 모아볼 수 있습니다.
-사진으로 추억하기
 내가 업로드한 여행 사진들을 모아볼 수 있습니다.
